# The Agentic Relay · presentation site

Homepage for my GD 503 studio project, built from my Figma homepage frame.

- `npm install` then `npm run dev` to run it locally
- `npm run build` to make the production build in `dist/`
- Deployed on Vercel (see `vercel.json`)

Card illustrations live in `src/art/Art.jsx`, hover build-ins in `src/hover.css`, and the in-site Astra window in `src/AstraWindow.jsx`.
